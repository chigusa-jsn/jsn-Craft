# jsn-Craft

MMO風の職業システムを追加する Minecraft MOD（NeoForge 1.21.1）。

## 目標（全体像）

- 1人が持てるのは **生活ジョブ1つ + 戦闘ジョブ1つ**。いつでも転職できる
- 生活ジョブ10種・戦闘ジョブ10種、それぞれの上位職10種ずつ、合体職10種ほど（合計約50）
- 頭の上に **肩書 / 戦闘ジョブとレベル / 生活ジョブとレベル** の3段表示

## いまできること（v0.1）

- 職業を選ぶ・転職する（前の職業のレベルは残る）
- 行動で経験値が入り、レベルが上がる
- 上位職の転職条件（例：木こり Lv.20 で「森の匠」に転職できる）
- 頭上の3段表示（周りのプレイヤーにも見える）
- データはセーブされ、死んでも消えない

サンプル職業：木こり（生活）、森の匠（生活・上位職）、戦士（戦闘）

## 動かし方

1. **IntelliJ IDEA Community** をインストール
2. IntelliJ で「開く」→ このフォルダ（`build.gradle` がある場所）を選ぶ
3. 初回は依存ファイルのダウンロードに数分かかるので待つ
4. 右側の Gradle パネル → `Tasks > mod development > runClient` をダブルクリック

コマンドで動かす場合：`./gradlew runClient`（Windows は `gradlew.bat runClient`）

## コマンド

| コマンド | 内容 |
|---|---|
| `/job` | 自分の職業とレベルを見る |
| `/job list` | 職業の一覧 |
| `/job change lumberjack` | 転職（OP・テスト用。ふだんは転職の神官から） |
| `/job title @s 森の守護者` | 肩書を付ける（OP） |
| `/job title @s clear` | 肩書を外す（OP） |
| `/job addxp life 500` | 経験値を足す（テスト用・OP） |

| `/job resetboard combat` | スキルボードをリセット（テスト用・OP） |

## スキルボード

職業レベルが1上がるごとにスキルポイント（SP）がもらえる（数は職業JSONの `skill_points_per_level`。剣士は2、Lv.50で98）。SPは職業ごとで、その職業のボードにだけ使える。
能力が上がるのは、今就いている職業のボードだけ（転職するとお休み、戻ると復活）。

ボードは職業JSONの `board` に書く。ツリー型も盤面型も同じ書き方。

```json
{ "id": "power1", "x": -2, "y": 1, "cost": 1, "links": ["root"],
  "name": "鋭刃 I", "icon": "minecraft:stone_sword",
  "effects": [ { "attribute": "minecraft:generic.attack_damage", "amount": 0.5 } ] }
```

| 項目 | 意味 |
|---|---|
| `x`, `y` | 盤面上の位置 |
| `start` | `true` なら最初から解放できる |
| `links` | つながっているマス。どれかを解放済みなら、このマスも解放できる |
| `cost` | 必要なSP |
| `effects` | 上がる能力。`operation` を `add_multiplied_total` にすると「○%アップ」 |

自分の頭上表示は **F5（三人称視点）** で確認できる。

## 職業の増やし方

`src/main/resources/data/jsn_craft/jsn_jobs/` に JSON ファイルを1つ足すだけ。Java は書かなくていい。

```json
{
  "name": { "text": "採掘師", "color": "gray" },
  "type": "life",
  "tier": "basic",
  "max_level": 50,
  "requires": [],
  "xp": [
    { "action": "break_block", "target": "minecraft:diamond_ore", "xp": 30 },
    { "action": "break_block", "target": "#minecraft:base_stone_overworld", "xp": 1 }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `name` | 表示名。色も付けられる |
| `type` | `life`（生活） / `combat`（戦闘） |
| `tier` | `basic`（基本職） / `advanced`（上位職） / `hybrid`（合体職） |
| `max_level` | 最大レベル |
| `requires` | 転職条件。合体職なら2つ書く |
| `xp` | 経験値のもらえる行動。上から順に見て、最初に当てはまったものだけ使う |

`action` は今のところ `break_block`（ブロックを壊す）と `kill_entity`（モブを倒す）。
`target` は ID（`minecraft:stone`）、タグ（`#minecraft:logs`）、何でも（`*`）。

## 依頼（クエスト）

依頼の流れ：**受付嬢から受ける → どこでも報告（納品）できる → 報酬は受付嬢から受け取る**。
Kキーのメニューの「依頼」タブでは、依頼を見る・報告する・あきらめるができる（受注と報酬の受け取りは受付嬢のそばでだけ）。同時に受けられるのは5件まで。
依頼でもらった肩書は `/job mytitle <肩書>` で付け替えられる（`/job mytitle clear` で外す）。

依頼は `src/main/resources/data/jsn_craft/jsn_quests/` に JSON を1つ足すだけ。
サーバーで運営が追加するときは、データパックの `data/<名前>/jsn_quests/` に置いて `/reload` すれば、止めずに増やせる。

```json
{
  "title": { "text": "【特別依頼】収穫祭" },
  "description": { "text": "カボチャを集めよう" },
  "category": "special",
  "repeat": "once",
  "start": "2026-11-01T00:00",
  "end": "2026-12-31T23:59",
  "objectives": [
    { "type": "deliver_item", "target": "minecraft:pumpkin", "count": 16 }
  ],
  "rewards": {
    "job_xp": [ { "job": "life", "amount": 300 } ],
    "items": [ { "id": "minecraft:golden_apple", "count": 1 } ],
    "title": "収穫祭の英雄"
  }
}
```

| 項目 | 意味 |
|---|---|
| `category` | `normal`（通常） / `job`（職業依頼） / `special`（運営の特別依頼） |
| `required_job`, `min_level` | 職業依頼の条件。その職業に就いていて、レベルが足りている人だけ |
| `repeat` | `once`（1回だけ） / `daily`（1日1回） / `always`（何度でも） |
| `start`, `end` | 受けられる期間。サーバーのPCの時刻で判定。書かなければいつでも |
| `objectives` | 目標。`break_block`（壊す） / `kill_entity`（倒す） / `deliver_item`（納品） / `reach_level`（職業レベル） |
| `label` | 目標の説明文（省略すると自動） |
| `rewards` | `job_xp`（`life` / `combat` / 職業ID）、`items`（通常報酬）、`title`（肩書）、`choices` と `choose`（選択報酬：候補の中から choose 個選ぶ） |

選択報酬の例（3つの中から1つ）：

```json
"rewards": {
  "items": [ { "id": "minecraft:bread", "count": 8 } ],
  "choices": [
    { "id": "minecraft:iron_sword" },
    { "id": "minecraft:iron_axe" },
    { "id": "minecraft:bow" }
  ],
  "choose": 1
}
```

選択報酬は、受付嬢のところで報酬を受け取るときに、候補のアイコンをクリックして選ぶ。

`"hide_rewards": true` にすると、受け取るまで報酬が「？？？？？ ×1」のように隠れる（選択報酬も「？」のアイコンになる）。エディターでは左下の「報酬：？？？で隠す」で切り替え。

## 受付嬢NPC

右クリックすると、依頼タブが開いた状態でメニューが出る。攻撃されても倒れず、その場から動かない。

- 置く：クリエイティブの「スポーンエッグ」タブにある「受付嬢のスポーンエッグ」、または `/summon jsn_craft:receptionist`
- 片付ける：クリエイティブでスニークしながら殴る、または `/kill`
- 見た目：`src/main/resources/assets/jsn_craft/textures/entity/receptionist.png`（アレックス型・64×64）を差し替える

## ゲーム内で依頼を作る（OP用）

| コマンド | 内容 |
|---|---|
| `/quest new` | 依頼エディターを開く |
| `/quest list` | ゲーム内で作った依頼の一覧。[編集] [停止] [削除] をクリックできる |
| `/quest edit custom_1` | 編集 |
| `/quest toggle custom_1` | 一時停止 ⇔ 再開（受注中の人はそのまま続けられる） |
| `/quest delete custom_1` | 削除 |

- 目標の対象は、ボタンを押すと一覧から選べる（壊す＝ブロック、倒す＝モブ、納品＝アイテム、Lv＝職業）。検索もできる。✋なら手に持っているアイテム
- 報酬アイテムは「選ぶ」でクリエイティブの一覧から（右上で個数）、✋で手に持っているアイテムを登録。アイコンをクリックすると外せる（4種類まで）
- 開始・終了はカレンダーから選ぶ。開始なし＝すぐ受けられる、終了なし＝ずっと受けられる
- 作った依頼はワールドのセーブデータに保存され、保存した瞬間に全員の一覧に出る

## スキル

- 職業レベルが上がると、決まったレベルでスキルを覚える（上位職になっても、通ってきた職業のスキルは使える）
- **アクティブ**：**Rでスキルモード**に切り替えると、ホットバーがスキルバーになり、**1〜5**で使える。もう一度Rで戻る
- **パッシブ**：覚えている間、常に効く
- スキルバーへのセットは、Kキーのメニューの「スキル」タブ（スキルをクリック → 枠をクリック、右クリックで外す）

スキルは `data/jsn_craft/jsn_skills/` にJSONで書き、職業JSONの `skills` で覚えるレベルを決める。
`"cast_time": 0.5` を付けると、0.5秒ためてから出る（足元に魔法陣、画面にためのゲージ、ため中は動きが遅くなる）。
スキルで与えたダメージは蒼、会心は金の数字で出る。

```json
{ "name": { "text": "斬り払い" }, "description": { "text": "前方の敵をまとめてなぎ払う。" },
  "icon": "minecraft:iron_sword", "type": "active", "effect": "sweep",
  "stamina": 15, "cooldown": 5, "power": 1.0, "radius": 3.5 }
```

| effect | 種類 | 中身 |
|---|---|---|
| `sweep` | アクティブ | 前方の敵をなぎ払う（攻撃力×power、radius 範囲） |
| `dash` | アクティブ | 前に踏み込む（power 勢い）。bonus があれば次の一撃が (1+bonus) 倍 |
| `slash_line` | アクティブ | 一直線（radius ブロック）の敵を斬る（攻撃力×power） |
| `whirlwind` | アクティブ | 周り radius の敵を amplifier 回連続で斬る（1回 攻撃力×power） |
| `parry` | アクティブ | duration 秒かまえ、その間の近接攻撃を無効にして 攻撃力×power で反撃 |
| `blink_slash` | アクティブ | 前へ radius ブロック駆け抜け、通り道の敵を斬る（攻撃力×power） |
| `buff` | アクティブ | duration 秒、target の能力値が +power（割合）|
| `potion` | アクティブ | target のポーション効果を duration 秒（amplifier で強さ） |
| `heal_area` | アクティブ | 自分と radius 内のパーティー仲間を power 回復 |
| `dodge` | パッシブ | 近接攻撃を chance の確率でかわす |
| `full_hp_bonus` | パッシブ | HP満タンで近接攻撃 +power（割合） |
| `tree_feller` | パッシブ | しゃがんで原木を切ると木を丸ごと倒す（1本ごとに stamina） |
| `replant` | パッシブ | 木の根元を切ると苗木を植え直す |
| `extra_drop` | パッシブ | target（タグ）のブロックで、chance の確率でドロップ2倍 |

- 置く：スポーンエッグ（黒と金の卵）、または `/summon jsn_craft:job_master`
- 片付ける：クリエイティブでスニークしながら殴る、または `/kill`
- 見た目：`src/main/resources/assets/jsn_craft/textures/entity/job_master.png`（スティーブ型・64×64）

## 忘却の宝珠（スキルボードのリセット）

転職の神官の画面の「ボードをリセット」から、戦闘ボードか生活ボードを選ぶと、忘却の宝珠を1つ使ってリセットできる。
今の職業と、そこに至るまでに通ってきた職業のボードがまとめてリセットされ、SPがすべて戻る。
宝珠はクリエイティブの「道具と実用品」タブにある（依頼の報酬にも使える）。

## 六角形のスキルボード（ドラクエ11風）

職業JSONに `"board_style": "hex"` を書くと、パネルが六角形で表示される。隣どうしのパネルはつながっていて、どこからでも広げられる。

パネルの種類：
- 能力値アップ：`{ "attribute": "...", "amount": 0.5 }`
- 技の強化：`{ "skill": "jsn_craft:sword/sweep", "field": "power_pct", "amount": 0.15 }`（field: power_pct / radius / cooldown / stamina / amplifier / duration / cast_time / chance）
- パッシブを覚える：`{ "grant": "jsn_craft:sword/board/last_stand" }`
- `"hidden": true` … ？パネル（隣を開けるまで中身が見えない）
- `"min_level": 40` … 鍵パネル（職業レベルが足りないと開けられない）
- `"big": true` … ★パネル（大きく表示）



新しいステータス：スキルダメージ、待ち時間短縮（最大50%）、消費ST軽減（最大50%）、被ダメージ軽減（最大60%）、吸血、職業経験値。
ボードでしか覚えられないパッシブ：背水の陣、連撃、戦意高揚、不屈。

## 上位職のボードと引き継ぎ

- 上位職・合体職は Lv.100 まで、1レベル3SP（Lv.100で297）。ボードは7周169枚、合計コスト約360
- **ステータスのパネルは、今就いている職業のボードだけ効く**
- 覚えた技とパッシブ、技の強化パネル、ボードで覚えたパッシブは、通ってきた職業から引き継ぐ
- 蒼天の剣聖（剣士の上位職、剣士Lv.30から）
- 上位職のパッシブ：追撃、炎刃、凍刃、光の盾、守護の陣・鼓舞の陣（パーティーへのオーラ）
- 剣聖の技：天翔蒼刃（Lv.10、`leap_slam`）、千刃乱舞（Lv.35、`flurry`）、奥義・天穹蒼月（Lv.70、`moon_fall`）
- 新ステータス：ボス特効（最大HP100以上の相手）、HP自然回復

## ボードの作り方（全職業共通）

六角形のボードは `tools/gen_board.py` で作る。職業ごとに `tools/boards/<職業>.json` を1つ書くだけ。

```
python3 tools/gen_board.py tools/boards/warrior.json   # 1つだけ
python3 tools/gen_board.py --all                       # 全部
```

設定ファイルで決めるのは、
- 区画（上・右下・左下）ごとのパネルの種類と **割合（weight）**
- 周ごとのコスト・強さの倍率
- ★や？などの特別なパネルを置く場所

くわしい書き方は `tools/gen_board.py` の先頭に書いてある。剣士（`warrior.json`）と剣聖（`sword_saint.json`）がお手本。

## 釣りミニゲーム（水辺の釣り師・大海の網主）

浮きが沈んだときに竿を引くと、釣りミニゲームが始まる（職業に関係なく全員）。

- 右クリック長押し（左クリック・スペースでも可）で緑の「キャッチ枠」が上がり、離すと下がる
- 枠が魚に重なっている間は右のゲージが溜まり、外れると減る。満タンで釣れる、空で逃げられる
- 一度も外さずに釣ると PERFECT（職業経験値1.5倍）
- Esc で閉じると逃げられたことになる
- 釣れる物はバニラの「釣りのドロップ表」で決まるので、他MODが追加した魚もそのまま釣れる
- ミニゲームなしでは何も釣れないので、放置釣り場では職業経験値がたまらない

難しさと魚の動き方は `data/<名前空間>/jsn_fishing/*.json` で決められる（書いていない物は、種類とレア度から自動で決まる）。

```json
{ "entries": [ { "target": "minecraft:pufferfish", "difficulty": 60, "behavior": "dart" } ] }
```

behavior は normal（ふつう） / smooth（なめらか） / dart（すばやい） / sinker（底にいがち） / floater（上にいがち）。

職業経験値は職業JSONの `"action": "fish"` で決める。target には アイテムID、`#タグ`、
`@fish`（魚）・`@junk`（ゴミ）・`@treasure`（お宝）・`@lord`（海の主）、`*`（何でも）が使える。上から順に、最初に当てはまったものが使われる。

海の主のドロップは `data/jsn_craft/loot_table/gameplay/fishing_lord.json`。

## 岩窟の掘り師・深淵の鉱脈王

- 経験値は鉱石が中心（`#c:ores/○○` のタグで判定するので、他MODの鉱石もだいたい入る）。石・深層岩は1、丸石は0
- シルクタッチで鉱石を掘ったときは経験値なし（置いて掘ってを繰り返せないように）
- 鉱脈掘り：ツルハシでしゃがみながら鉱石を掘ると、つながった鉱石をまとめて掘る。道具が壊れそうになったら止まる
- 鉱石感知・大地の鼓動：鉱石の輪郭が壁越しに色つきで光る（ダイヤ水色、エメラルド緑、金黄色、鉄うす茶、銅オレンジ、レッドストーン赤、ラピス青、石炭灰色、古代の残骸茶色、他MODの鉱石は紫）
- 広域掘り・爆破採掘：ツルハシで掘れるブロックだけ。黒曜石やチェストなどは巻き込まない

## 大地の耕し手・豊穣の守り手

- 経験値は「実った作物を収穫したとき」だけ（`"action": "harvest"`）。スイカとカボチャは茎につながっているときだけ数える
- 収穫の心得：実った作物を右クリックで収穫して植え直す（しゃがむと普通の右クリック）
- 耕しの鍬：鍬で3×3をまとめて耕す（しゃがむと1マスだけ）
- 他MODの作物も、バニラの作物と同じ仕組み（CropBlock）で作られていれば対象になる

## 魚図鑑とランク

- 魚は `data/<名前空間>/jsn_fish/*.json` で1種類ずつ決める（書き方は `FishSpecies.java` の説明を見てね）
- バニラの魚（タラなど）が釣れたとき、その場所・時間・天気・月に合った魚に入れ替わる。他MODの魚はそのまま
- ランク：コモン（白）・アンコモン（緑）・レア（青）・エピック（紫）・レジェンド（金）
  - レアは水辺の釣り師Lv10、エピックはLv25、レジェンドは大海の網主から釣れる
  - ランクが高いほどミニゲームが難しく、職業経験値が多い（コモン1倍〜レジェンド8倍）
  - 幸運が高いとレア以上が出やすい
- 釣るたびにサイズ（cm）が決まり、図鑑に「釣った数」と「最大サイズ」が記録される
- ジョブメニュー（Kキー）の「図鑑」タブで見られる。まだ釣っていない魚は「？」で、釣れる場所のヒントだけ見える
- 新しい魚の絵は `tools/gen_fish_art.py` で作っている（`--preview 出力.png` で一覧画像）

## 溶岩釣り（ネザーの魚）

- 水辺の釣り師Lv20のスキル「溶岩釣り」で開放（大海の網主にも引き継がれる）
- 溶岩に浮きを投げると、溶岩の表面に浮かぶ。炎の筋が近づいてきて、浮きが沈んだ（溶岩が跳ねた）ら竿を引く
- ネザーの溶岩ではネザーの魚12種が釣れる。それ以外の溶岩ではガラクタやお宝だけ
- 溶岩のガラクタとお宝は `data/jsn_craft/loot_table/gameplay/lava_fishing_junk.json` と `lava_fishing_treasure.json`

## エンドの魚

- エンドで、バケツで置いた水に釣り糸を垂らすと、エンドの魚10種が釣れる（島ごとに違う魚）
- レジェンドの「終焉の龍魚」は、エンダードラゴンを倒した後だけ
- これで図鑑は全59種（地上37・ネザー12・エンド10）

## 炎の調理師・宴の料理長と調理台

- **調理台**（鉄インゴット・焚き火・かまど・木材で作る）を右クリックすると、調理の画面が開く
- 材料の枠4つ＋隠し味の枠1つ。材料を入れて「調理する」を押すと、少し待って料理ができる
- 料理を作れるのは **炎の調理師・宴の料理長だけ**（レシピごとに必要なレベルがある。宴の料理長は 50＋レベル として数える）
- 料理には **品質（★1〜★3、宴の料理長は★4「至高」も）** があり、満腹度・バフの時間・強さが上がる
  - 品質は、調理師のレベル・料理の腕前・スキル・隠し味・材料の魚のランクで上がりやすくなる（レジェンドの魚を使うと必ず★3以上）
- **隠し味**を入れると、隠し味ごとのバフが料理につく（`data/<名前空間>/jsn_seasonings/*.json`）
- レシピは `data/<名前空間>/jsn_cooking/*.json`（書き方は `CookingRecipe.java` の説明を見てね）
- 料理と調理台の絵は `tools/gen_dish_art.py` で作っている
- 職業経験値は `"action": "cook"`（レシピの xp × 品質 × ルールの xp）
- ボードの技の強化パネルに `"field": "power"`（効果をそのまま足す）を追加した

## 新しい作物と加工食材

- 作物11種：米・玉ねぎ・大豆・大麦（取れた物をそのまま植える）、トマト・キャベツ・唐辛子・ホップ（種がある）、ブドウ・レモン・梅（苗を植える果樹）
- 種は、草やシダを壊すと10%で出る（ハサミ以外）
- 苗は、葉っぱを壊すとたまに出る（オーク・ダークオーク→ブドウ、ジャングル→レモン、桜→梅）
- 果樹は、実ったら右クリックで実だけ取れて、木は残る（また実るまで待つ）
- 加工食材12種は調理台で作る（炎の調理師Lv1から）：ごはん・小麦粉・パン生地・塩（水バケツ）・麹・味噌・醤油・バター・チーズ（牛乳バケツ）・出汁・麦芽・トマトソース
- 絵は `tools/gen_crop_art.py`

## 料理図鑑・置ける料理

- 料理は全50品（ふつう15・ごちそう18・逸品11・伝説6）。データは `tools/dishes.py` にまとめてあり、`python3 tools/dishes.py` でレシピJSONと言語ファイルを作り直せる
- Kキーのメニューの「図鑑」タブで「魚 / 料理」を切り替えられる。料理図鑑は作った数と最高の★を記録し、まだ作っていない料理も材料と必要レベルが見える（レシピ帳の代わり）
- 伝説の料理（レジェンドの魚を使う）を作ると、サーバー全員にお知らせ
- 同じ材料に合うレシピが2つあるときは、名指しの材料が多いほう（例：マグロなら寿司より大トロ丼）が優先される
- **料理を置く**：料理を持ってしゃがみ右クリックで、ブロックの上に置ける。置いた料理は右クリックで食べられ（誰でも、バフもつく）、しゃがみ右クリックで拾える
